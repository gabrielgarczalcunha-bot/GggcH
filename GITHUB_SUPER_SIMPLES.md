# 📱 GUIA SUPER SIMPLES - GitHub Pages

## 🎯 EM 5 PASSOS:

---

## 1️⃣ CRIAR CONTA (2 minutos)

```
👉 Acesse: github.com

┌─────────────────────────────────┐
│  [GitHub Logo]                  │
│                                 │
│  Email: ____________            │
│  Password: ________             │
│  Username: ________             │
│                                 │
│  [Sign up for GitHub]           │
└─────────────────────────────────┘

👉 Clique "Sign up"
👉 Verifique seu email
✅ Conta criada!
```

---

## 2️⃣ CRIAR REPOSITÓRIO (1 minuto)

```
👉 Clique no + (canto superior direito)
👉 Clique "New repository"

┌─────────────────────────────────┐
│  Create a new repository        │
│                                 │
│  Repository name:               │
│  [wealth-farm]                  │
│                                 │
│  ☑ Public                       │
│  ☑ Add a README file            │
│                                 │
│  [Create repository]            │
└─────────────────────────────────┘

👉 Clique "Create repository"
✅ Repositório criado!
```

---

## 3️⃣ ENVIAR ARQUIVO (2 minutos)

```
👉 Clique "Add file"
👉 Clique "Upload files"

┌─────────────────────────────────┐
│  Upload files                   │
│                                 │
│  ╔═══════════════════════════╗  │
│  ║                           ║  │
│  ║   Arraste arquivos aqui   ║  │
│  ║   ou clique para escolher ║  │
│  ║                           ║  │
│  ╚═══════════════════════════╝  │
│                                 │
│  [Commit changes]               │
└─────────────────────────────────┘

👉 Arraste wealth-farm.html
👉 RENOMEIE para: index.html ⚠️ IMPORTANTE!
👉 Clique "Commit changes"
✅ Arquivo enviado!
```

---

## 4️⃣ ATIVAR SITE (2 minutos)

```
👉 Clique "Settings" (topo da página)
👉 Clique "Pages" (menu lateral)

┌─────────────────────────────────┐
│  GitHub Pages                   │
│                                 │
│  Source:                        │
│  [main] [/ (root)] [Save]       │
│                                 │
│  ⏳ Building...                 │
└─────────────────────────────────┘

👉 Escolha "main" e "/ (root)"
👉 Clique "Save"
👉 AGUARDE 2 minutos ⏰
👉 Recarregue a página (F5)

┌─────────────────────────────────┐
│  ✅ Your site is live at:       │
│  https://user.github.io/repo/   │
│                                 │
│  [Visit site]                   │
└─────────────────────────────────┘

✅ Site no ar!
```

---

## 5️⃣ ACESSAR SEU SITE (10 segundos)

```
👉 Copie a URL:
https://seu-usuario.github.io/wealth-farm/

👉 Cole no navegador
👉 Pressione Enter

✅ SEU SITE ESTÁ ONLINE! 🎉
```

## ⚠️ ERROS COMUNS:

### ❌ "404 - Página não encontrada"
**Causa**: Arquivo não se chama `index.html`
**Solução**: Renomeie para `index.html`

### ❌ "Site não carrega"
**Causa**: Não aguardou tempo suficiente
**Solução**: Aguarde 2-3 minutos e recarregue (Ctrl+F5)

### ❌ "Não encontro Settings"
**Causa**: Está fora do repositório
**Solução**: Entre no SEU repositório first

### ❌ "Não tem opção Pages"
**Causa**: Repositório é privado
**Solução**: Mude para público em Settings
