## 🆘 PROBLEMAS COMUNS:

### "Não consigo adicionar à tela inicial"
→ Tente no Chrome (navegador recomendado)
→ Certifique-se que está usando HTTPS

### "Não encontro o botão Download no Emergent"
→ Procure por: Export, ⬇️, Download Code, Save
→ Ou use os 3 pontinhos (⋮) no projeto

### "O ZIP não extrai"
→ Instale: RAR ou ZArchiver da Play Store
→ Ou use o app "Arquivos" nativo

### "APK não instala"
→ Configurações → Segurança → Ativar "Fontes Desconhecidas"
→ Ou "Instalar apps desconhecidos" (Android 8+)
